# Referências visuais — interface essencial

Base de execução do [slice 25](../../slices/25-interface-essencial.md) e da [issue #30](https://github.com/rleiteoliveira/gymsheet/issues/30).

## Veredito do dono — 06/09/2026

Laboratório de quatro variantes da inicial. Não é código de produto.

| Variante | Decisão |
|---|---|
| **A · Essencial** | Base. Menu à esquerda, data pequena, nome serifado com seta, um CTA claro, sem dock. Coincide com o contrato já escrito no slice 25. |
| B · Dock | Descarta. A barra inferior é adição que não agrada e o slice 25 já a remove. |
| C · Densa | Pior. Marca em bloco, slogan, cards e dock descrevem o *antes*, não o alvo. |
| D · Extrema | Fora desta entrega. O vazio sem conteúdo parece abandono. Só revisitar se um slice futuro ocupar esse espaço com histórico e uma transição explícita. Não preencher a inicial do 25 para “não ficar vazia”. |
